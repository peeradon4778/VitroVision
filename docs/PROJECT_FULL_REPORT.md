## 1. บทคัดย่อ (Abstract)

โครงงานนี้พัฒนาและประเมินระบบคัดกรอง**ความพร้อมอนุบาล** (acclimatization readiness) ของต้นพืชเพาะเลี้ยงเนื้อเยื่อแบบ**ไม่ทำลายตัวอย่าง** ผ่านขวดแก้ว โดยใช้แบบจำลองพื้นฐาน **Segment Anything Model 3 (SAM3)** ในโหมด **Promptable Concept Segmentation (PCS)** แบบ zero-shot แบ่งส่วนภาพต้นด้วยพรอมป์ข้อความ 5 คำ (plant, leaf, shoot, stem, root) คำนวณลักษณะเชิงปริมาณ 6 กลุ่ม และจัดกลุ่มความพร้อมด้วยกฎที่ปรับได้

ระบบใช้เพียงสมาร์ตโฟน + Google Colab ฟรี + โมเดล open-source (ต้นทุนต่ำสุด) ผลนำร่องกับ**ภาพจริง 100 ขวดพริกจินดา** ได้ผลจริง และเมื่อตรวจสอบกับ**ค่าอ้างอิงจากผู้ประเมิน (ground truth)** พบว่า **เกณฑ์ความพร้อมที่ถูกต้องคือ "ความสูง/ความโตของต้น" ไม่ใช่ "ความแน่นเต็มขวด" (coverage)** โดยกฎ `height_proxy ≥ 0.275` ให้ accuracy = **0.755** และ sensitivity = **0.917** ซึ่ง**ผ่านสมมติฐาน H₂** (accuracy ≥ 0.70, sensitivity ≥ 0.60) ขณะที่กฎ coverage ซึ่งใช้เดิมให้ accuracy เพียง 0.43

## 2. บทนำ (Introduction)

### 2.1 จากข้อมูลโลกจริงสู่ดิจิทัล (real-world data → digital)

การปฏิรูปดิจิทัลในภาคการเกษตรและวิทยาศาสตร์พืชนำข้อมูลจากโลกกายภาพเข้าสู่ระบบดิจิทัลอย่างรวดเร็ว (real-world data → digital) โดยมีแนวคิดหลักที่ได้รับความสนใจอย่างมาก ได้แก่ **digital twin** ซึ่งเป็นการสร้างแบบจำลองดิจิทัลของวัตถุจริงเพื่อใช้ติดตาม คาดการณ์ และปรับปรุงการตัดสินใจ (MDPI Agronomy, 2026) และ **การวัดฟีโนไทป์แบบ high-throughput ที่ใช้ AI** ซึ่งอาศัยการเรียนรู้เชิงลึก (deep learning) และคอมพิวเตอร์วิทัศน์ (computer vision) เป็นแกนกลางของการเกษตรแม่นยำ (precision agriculture) และการเฝ้าติดตามผลผลิต (crop monitoring) (Frontiers, 2025) งานทบทวนล่าสุดยืนยันว่า AI กลายเป็นศูนย์กลางของการติดตามผลผลิตแบบเรียลไทม์ การตัดสินใจแบบข้อมูลนำ (data-driven) และการวัดลักษณะพืช**แบบไม่ทำลาย** (non-destructive phenotyping)

ข้อดีที่ชัดเจนที่สุดของแนวทางนี้คือการลดภาระแรงงานคนในขั้นตอนที่ซ้ำซาก เช่น การวัดและนับด้วยมือ ระบบอัตโนมัติ เช่น **CropPhenoX** และ **TraitDiscover** ช่วยสกัดลักษณะเชิงปริมาณจากภาพจำนวนมากโดยอัตโนมัติ ขณะที่เครื่องมืออย่าง **RootXplorer** ให้การวัดระบบรากแบบ 3 มิติ ส่วนในด้านการแบ่งส่วนภาพ แบบจำลองพื้นฐานอย่าง **Segment Anything Model (SAM)** ทำให้สามารถแบ่งส่วนต้นพืชแบบ zero-shot ได้โดยไม่ต้องมีชุดข้อมูลขนาดใหญ่ที่กำกับด้วยมือ (Frontiers, 2025) อย่างไรก็ตาม งานทบทวนจำนวนหนึ่งยังชี้ข้อจำกัดสำคัญ ได้แก่ การขาดแคลนข้อมูล การถ่ายโอนแบบจำลองไปยังสภาพแปลงจริงที่แตกต่างกัน (generalization) และค่าใช้จ่ายสูงในการสร้างชุดข้อมูลขนาดใหญ่สำหรับงานทั่วไป

### 2.2 เพาะเลี้ยงเนื้อเยื่อ: อุตสาหกรรมจริงที่กำลังเติบโต

การเพาะเลี้ยงเนื้อเยื่อ (in vitro) เป็นเทคโนโลยีสำคัญสำหรับการขยายพันธุ์และผลิตต้นกล้าพันธุ์ดีที่ปราศจากโรคของพืชเศรษฐกิจหลากหลายชนิด ทั้งในระดับโลกและระดับประเทศ ในเชิงอุตสาหกรรม ตลาดเพาะเลี้ยงเนื้อเยื่อมีมูลค่าประมาณ **USD 525–669 ล้านในปี 2025** และคาดการณ์ว่าจะเติบโตด้วยอัตรา CAGR **8.5–9.6%** ในทศวรรษถัดไป โดยมีปัจจัยขับเคลื่อนจากพันธุวิศวกรรม ความต้องการสารประกอบทางการแพทย์ และการประยุกต์ใช้ในภาคการเกษตร (Polaris, 2025) ซึ่งบ่งชี้ว่าเทคโนโลยีนี้ไม่เพียงมีความสำคัญทางวิทยาศาสตร์ แต่ยังมีความสำคัญทางเศรษฐกิจและมีการขยายตัวในเชิงพาณิชย์

### 2.3 ปัญหาคอขวด: การตัดสินใจย้ายต้นออกอนุบาล

แม้เพาะเลี้ยงเนื้อเยื่อจะมีศักยภาพสูง ขั้นตอนที่เป็นคอขวดและมีผลต่อคุณภาพผลผลิตมากที่สุดขั้นตอนหนึ่งคือการตัดสินใจว่าเมื่อใดควรย้ายต้นออกจากขวดสู่อนุบาล (acclimatization) ซึ่งปัจจุบันทำ**ด้วยสายตาเป็นรายขวด** กระบวนการนี้ใช้แรงงานมากและมีค่าใช้จ่ายสูง โดยค่าแรงงานคิดเป็นสัดส่วนสูงถึง **60–70% ของต้นทุนการผลิต** (Bethge et al., 2023) ยิ่งไปกว่านั้น ผลการประเมินด้วยสายตา**มีความแปรปรวนระหว่างผู้ประเมิน** (observer variability) (Zhang et al., 2026) และแม้แต่ผู้ประเมินคนเดียวกันก็อาจให้ผลไม่สอดคล้องกันในเวลาต่างกัน การตัดสินใจที่ผิดพลาด (ย้ายเร็วหรือช้าเกินไป) อาจทำให้เนื้อเยื่อเกิดความผิดปกติ เช่น **hyperhydricity** (อวบน้ำมากเกิน) หรือการตายของเนื้อเยื่อ ซึ่งส่งผลต่ออัตราการรอดและคุณภาพของต้นกล้าที่จะนำไปขยายต่อ

นอกเหนือจากปัญหาเรื่องแรงงานและความไม่คงเส้นคงวาแล้ว การวัดสภาพต้นในขวดยังถูกจำกัดด้วยตัวขวดแก้วปิด เนื่องจาก**การเปิดขวดเพื่อตรวจวัดสภาพเสี่ยงต่อการปนเปื้อน** (contamination) ซึ่งเป็นข้อจำกัดที่สำคัญมากในงานเพาะเลี้ยงเนื้อเยื่อ ดังนั้น ระบบที่ช่วยตัดสินใจจึงจำเป็นต้องเป็นแบบ**ไม่ทำลายตัวอย่าง (non-destructive)** คือประเมินโดยไม่ต้องเปิดขวดหรือสัมผัสต้นโดยตรง

### 2.4 งานล่าสุดด้านการวัดต้นเพาะเลี้ยงเนื้อเยื่อแบบไม่ทำลาย

ในช่วงไม่กี่ปีมานี้ มีความพยายามนำระบบเซนเซอร์และ AI มาใช้ในเพาะเลี้ยงเนื้อเยื่อเพื่อแก้ปัญหาดังกล่าว ตัวอย่างที่โดดเด่น เช่น ระบบ **"Phenomenon"** ของ Bethge et al. (2023) ซึ่งเป็นระบบ multi-sensor ต้นทุนต่ำสำหรับการเฝ้าติดตามสภาพเพาะเลี้ยงเนื้อเยื่อ **ในสถานที่จริงแบบไม่ทำลาย** (ใน-situ, non-destructive) และแพลตฟอร์ม **EcoBOT** สำหรับการวัดฟีโนไทป์ด้วย AI/ML ภายใต้สภาพปลอดเชื้อ (axenic) รวมถึงงานด้าน deep learning ที่ใช้โครงข่ายประสาทแบบสนใจ (attention) เช่น **EfficientNet-B7-CBAM** ในการจำแนกคุณภาพต้นกล้า และการสร้างแบบจำลอง 3 มิติของต้นกล้าด้วย **PointNet++** เพื่อลดข้อผิดพลาดจากการวัดด้วยมือ

ในเชิงพาณิชย์ ยังมีระบบเช่น **Viscon PhytoFlow Transplanter** ที่ทำการคัดเลือกและย้ายต้นอ่อนระยะแรกจากอาหารเลี้ยงเชื้อโดยอัตโนมัติ และงานที่ผสาน near-infrared spectroscopy กับ machine learning เพื่อเพิ่มประสิทธิภาพการเพาะเลี้ยง (เช่น การช่วยเพาะเมล็ดองุ่นที่เพิ่มการพัฒนาของเอ็มบริโอและอัตรารอดของต้นอ่อน) ขณะเดียวกัน งานทบทวนยังชี้ว่าการประยุกต์ใช้ AI ในเพาะเลี้ยงเนื้อเยื่อโดยรวมยัง**อยู่ในระยะวิจัย/ระยะเริ่มต้น** และส่วนใหญ่เป็นการออกแบบในแนวทาง "plant-to-sensor" (ติดตั้งเซนเซอร์ใกล้ตัวต้น) มากกว่าการวิเคราะห์ภาพถ่ายจากระยะไกลจริง และยังมีข้อจำกัดด้าน segmentation artifacts ในการคำนวณลักษณะอัตโนมัติ

### 2.5 แบบจำลองพื้นฐาน (Foundation Models) และการแบ่งส่วนแบบ zero-shot

ความก้าวหน้าสำคัญที่เปิดโอกาสใหม่ให้งานนี้คือ **แบบจำลองพื้นฐาน (foundation model)** สำหรับการแบ่งส่วนภาพ ซึ่งปัจจุบันถูกนำมาใช้ในงานฟีโนไทป์ของพืชอย่างแพร่หลาย ตัวอย่างเช่น **Segment Any Plant (SAP)** (2026) ซึ่งใช้แนวทาง few-shot ในการวัดการเจริญของต้น Arabidopsis รากและทานตะวันตามเวลา และงานอีกหลายชิ้นที่พัฒนาแบบจำลอง เช่น **DepthCropSeg++** และ **PlantSAM** เพื่อปรับปรุงความแม่นยำและการถ่ายโอนไปสู่สภาพแปลงจริง แบบจำลอง **Segment Anything Model (SAM)** และรุ่นต่อมา **Segment Anything Model 3 (SAM3)** (Carion et al., 2025) ในโหมด **Promptable Concept Segmentation (PCS)** เป็นอีกก้าวสำคัญ เพราะช่วยให้แบ่งส่วนภาพตามแนวคิดที่ระบุด้วยข้อความ (เช่น plant, leaf, shoot) ได้ **โดยไม่ต้องฝึกแบบจำลองใหม่** (zero-shot) ซึ่งช่วยลดต้นทุนและเวลาที่ต้องใช้ในการสร้างข้อมูลชุดใหญ่

อย่างไรก็ตาม งานทบทวนยังชี้ข้อจำกัดว่า zero-shot เหมาะกับงานที่ง่ายกว่า (เช่น การแบ่งส่วนใบระดับ leaf-level) แต่การแบ่งส่วนพืชทั้งต้นที่มีใบซ้อนทับกัน (hierarchical/whole-plant segmentation) มักยังต้องการข้อมูลฝึกซ้ำ และความแม่นยำขึ้นอยู่กับการออกแบบพรอมป์ข้อความ (prompt-sensitive) อย่างมาก (Dubois et al., 2026)

### 2.6 ช่องว่างของงานและแนวทางของโครงงานนี้

จากการทบทวนข้างต้น ยังไม่มีระบบต้นทุนต่ำที่ใช้เพียงสมาร์ตโฟนถ่ายภาพขวดเพาะเลี้ยง แล้วแบ่งส่วนต้นด้วยแบบจำลองพื้นฐานแบบ zero-shot **ผ่านขวดแก้วปิด** (ซึ่งมีปัญหา refraction, glare, ฝ้า และไอน้ำ) เพื่อวัดลักษณะเชิงปริมาณและจัดกลุ่มความพร้อมอนุบาล **แบบข้ามชนิด** โดยไม่ต้องฝึกแบบจำลองใหม่ต่อชนิด งานที่ใกล้เคียงที่สุด (เช่น Regni et al., 2025) ใช้ภาพ 3D วัดพื้นที่ปกคลุมต่อขวด แต่จำกัดชนิดและยังไม่ใช่ระบบจัดกลุ่มความพร้อมแบบไม่ทำลาย

โครงงานนี้จึงพัฒนาและประเมินระบบคัดกรองความพร้อมอนุบาลแบบไม่ทำลายผ่านขวดแก้ว โดยใช้ **SAM3 PCS** แบ่งส่วนภาพต้นด้วยพรอมป์ข้อความ 5 คำ (plant, leaf, shoot, stem, root) คำนวณลักษณะเชิงปริมาณ 6 กลุ่ม และจัดกลุ่มความพร้อมแบบ อัตโนมัติ — มุ่งให้เป็นระบบ**ต้นทุนต่ำ** (สมาร์ตโฟน + Google Colab + โมเดล open-source) ที่**ทำงานข้ามชนิด** และ**ไม่ทำลายตัวอย่าง** ซึ่งจะช่วยลดภาระแรงงาน ลดความแปรปรวนของการประเมิน และยกระดับการตัดสินใจในห้องปฏิบัติการเพาะเลี้ยงเนื้อเยื่อ

## 3. วัตถุประสงค์และสมมติฐาน

**วัตถุประสงค์:**
1. สร้างชุดข้อมูลภาพถ่ายจริงผ่านขวดแก้วชุดแรก (100 ขวด พริกจินดา) พร้อม metadata
2. สร้าง pipeline แบ่งส่วน + วัดเชิงปริมาณด้วย SAM3 PCS แบบ zero-shot
3. ประเมินเปรียบเทียบกับวิธีพื้นฐาน (SAM2, YOLO-seg, classical) ด้วย mIoU/Dice/F1 [PLAN]
4. ตรวจสอบความถูกต้องของระบบกับค่าอ้างอิงจากผู้ประเมิน (ground truth)

**สมมติฐาน:**
- **H₁ (segmentation):** SAM3 PCS segment ต้นผ่านขวดแก้วที่มี glare/ฝ้า/ไอน้ำได้ โดย mIoU ≥ 0.65 และสูงกว่า baseline [PLAN — ยังรอ ground_truth_masks]
- **H₂ (การจัดกลุ่ม):** ชุด feature ของ SAM3 จำแนกความพร้อมอนุบาลได้ถูกต้อง ≥ 70% และ sensitivity ของกลุ่มพร้อมอนุบาล ≥ 0.6 เทียบผู้ประเมิน **[RESULT — ผ่านด้วยกฎ height-based]**

## 5. วิธีดำเนินการ (Methodology / Pipeline)

### 5.1 ภาพรวมระบบ (diagram เต็มใน `docs/diagrams.md`)
```
ภาพขวด → [SAM3: detect ขวด (ROI)] → [SAM3 PCS: 5 prompts] → [extract 6 กลุ่ม feature] → [rule verdict] → [CSV/XLSX + report.html]
```

### 5.2 การแบ่งส่วนภาพ (SAM3 PCS)
- โมเดล: `facebook/sam3` (gated, ต้อง HF token) — รันบน GPU (Colab T4) [FACT — Carion et al., 2025]
- พรอมป์ 5 คำ: `plant, leaf, shoot, stem, root`
- ตรวจจับขวด (prompt "glass jar bottle") เพื่อกำหนด ROI ขวด
- ค่าเกณฑ์: score ≥ 0.5, mask ≥ 0.5
- **พบข้อจำกัด:** ระบบรากจับได้แค่ 1/100 ภาพ (พอร์ม "root" ผ่านขวดแก้วไม่ได้ผล) [OPEN]

### 5.3 Feature 6 กลุ่ม
| กลุ่ม | ตัวแปร |
|---|---|
| โครงสร้าง | projected area, height/width proxy, coverage_ratio |
| อวัยวะ | leaf_count, shoot_count, stem_count, root_count |
| ความซับซ้อน | hull_ratio |
| สี | green/red/yellow ratio (HSV) |
| คุณภาพภาพ | glare_score, condensation_score |
| การตัดสินใจ | verdict + confidence + readiness_index |

### 5.4 กฎการตัดสินใจ (verdict rule)
- **เดิม:** ใช้ `coverage_ratio` (ความแน่นเต็มขวด) — **พบว่าผิด** (validation ให้ acc 0.43)
- **ใหม่ (อัปเดต 2026-08-26):** ใช้ `height_proxy ≥ 0.275` → **พร้อมอนุบาล**, else → **ยังไม่พร้อม** (อิงนิยาม "ต้นสมบูรณ์/โตพอ/พร้อมย้าย")
- `height_proxy` ไม่ต้องอาศัย ROI ขวด จึงจัดได้ทุกภาพ
- ความมั่นใจ `confidence = base × (1 − glare/100)`; `readiness_index = 0.5·height + 0.3·width + 0.2·green`

### 5.5 การประมวลผลบน Colab
รัน headless: `python sam3_growth_pipeline.py --data ... --out ... --config config.json` ผลเป็น CSV/XLSX + overlays/ + plots/ + report.html และมี checkpoint (`_progress.csv`) กันค้างกลางทาง. แก้บั๊ก RAM: เก็บ mask เฉพาะ 6 ภาพแรก (กันหน่วยความจำพังที่ ~51 ภาพ)

## 6. ผลการทดลอง (Results)

### 6.1 ผลรันชุด 100 ขวด
| เมตริก | ค่า |
|---|---|

| Corr (sanity) | coverage↔area **0.949**, leaf↔coverage **0.852**, green↔healthy **0.910**, coverage↔height **0.701**, leaf↔shoot **0.534** |

### 6.2 Validation กับค่าอ้างอิงจากมือ (ground_truth.csv, 100 ภาพ)

| Feature | n | r | หมายเหตุ |
|---|---|---|---|
| leaf_count | 80 | 0.585 | 20 ภาพหนาแน่นเกิน(leaf>30)ตัดออก |
| shoot_count | 100 | 0.483 | |
| **height** | 100 | **0.638** | ดีสุด |
| width | 80 | 0.477 | |
| root_count | 100 | 0.150 | อ่อน — ราก detect แย่ |
| area | 80 | 0.398 | หน่วย px vs cm² ไม่ตรง |

**Level C — Confusion matrix (verdict vs ผู้ประเมิน):**
| Rule | Accuracy | Sensitivity | F1 | MCC |
|---|---|---|---|---|
| coverage ≥ 0.20 (เดิม) | 0.43 | 0.15 | 0.24 | 0.03 |

## 7. การอภิปรายผล (Discussion)

1. **เกณฑ์ความพร้อม:** ผลชัดเจนว่าความพร้อมเป็นเรื่อง**การเจริญ/ความโต** ไม่ใช่ความหนาแน่น — นี่คือข้อค้นพบที่ท้าทายสมมติฐานเดิมของหลายงานที่วัดแค่ "พื้นที่ปกคลุม"
2. **ระบบราก:** ยังจับไม่ได้ผล (1/100) ผ่านขวดแก้ว — เป็นข้อจำกัดทางเทคนิคที่ต้องแก้ (prompt ใหม่/วิธีใหม่) ก่อนใช้อ้าง root_ratio
3. **ข้อจำกัดของผล:** เป็น pilot (n=98, **ผู้ประเมินคนเดียว**, **ชนิดเดียว**) — ยังต้องยืนยัน inter-rater + ขยายชนิด
4. **Prompt sensitivity:** SAM3 ไวต่อถ้อยคำพรอมป์ (Dubois et al., 2026) → ผลขึ้นกับการออกแบบพรอมป์ จึงต้องแจ้งชุดพรอมป์ที่ใช้
5. **ความถูกต้อง vs ความสมเหตุผล:** ผลนี้เป็นการ**ตรวจความถูกต้อง (validation)** กับค่าอ้างอิงมือ (ต่างจาก sanity check เดิม) แต่ยังไม่ครอบคลุม Level A (mIoU ของ mask)

## 8. สรุปและข้อจำกัด

**สรุป:** ระบบวัดต้นในขวดแบบไม่ทำลายด้วย SAM3 zero-shot ทำงานได้จริงบนชุด 100 ขวด และเมื่อยึดเกณฑ์ความพร้อมตามนิยามผู้เชี่ยวชาญ (ความโต/ความสูง) ให้ผลจัดกลุ่มสอดคล้องกับมนุษย์ในระดับที่ผ่านสมมติฐาน (acc 0.755, sens 0.917)

**ข้อจำกัด (ซื่อตรง):**
- [OPEN] ระบบรากตรวจจับไม่ได้ผล (1/100)

## 10. เส้นทางต่อยอด (Future Work) [PLAN]

1. **จาก classifier → predictor (time-series):** ใช้ชุด 3 วันสร้าง growth curve + ทำนาย**อัตราการเจริญ**และ**เวลาที่จะพร้อมย้าย** — ยกระดับจาก "พร้อมไหม" เป็น "จะพร้อมเมื่อไร"
2. **ข้ามชนิด (multi-species zero-shot):** ทดสอบกับกล้วยไม้/กล้วย เพื่อพิสูจน์ generalization (ไม่ retrain)
3. **เปิดข้อมูล (FAIR) + baseline ครบ:** เปิด dataset + เปรียบเทียบ SAM2/YOLO-seg/classical ด้วย mIoU/Dice
4. **แอปมือถือ (deployment):** ต่อยอด `src/android/` เป็นแอป "ถ่ายภาพ → verdict เร็ว" สำหรับแล็บจริง
