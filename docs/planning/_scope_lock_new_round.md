## สถานะภายใน (สถานะการอ้างอิง)

- `[FACT]` = ตรวจแล้วจากข้อมูล/paper จริง
- `[PLAN]` = วิธีที่วางแผน ยังไม่ใช่ผล
- `[RESULT]` = ผลทดลองจริง มีไฟล์รองรับ
- `[OPEN]` = ยังต้องทำ/ตัดสินใจ

## สมมติฐาน (ตามข้อเสนอ)

- **H1 (แบ่งส่วนภาพ):** SAM3/U-Net แบ่งส่วนต้นผ่านขวดแก้วที่มี glare/ไอน้ำ/ความโค้ง ได้ mIoU ≥ 0.65 เทียบ ground truth
- **H2 (ประยุกต์):** ชุด feature จาก mask โดยเฉพาะ height_proxy จัดกลุ่มความพร้อมอนุบาลได้ถูกต้อง ≥ 70% พร้อม sens ≥ 0.6 (ผลนำร่องชี้ทิศทาง)
