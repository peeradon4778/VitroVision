## 🏁 เกณฑ์ตัดสิน "โมเดลของเรา" (ต้องครบทุกข้อ ถึงจะเรียกว่าได้)

| # | เงื่อนไข | ความหมาย | สถานะ |
|---|---|---|---|
| G1 | มี **โมเดลฝึกจริง** (weights) | ไม่ใช่แค่เรียก SAM3 แต่มี `unet_model.pt`/yolo ที่ฝึกจากข้อมูลเรา | ⚙️ รอรัน |
| G2 | ฝึก/ประเมินด้วย **ground truth มนุษย์** (Level A mIoU) | ตัวเลข mIoU/Dice **เทียบมนุษย์** ไม่ใช่เทียบ pseudo ของ SAM3 | 🔴 ยังไม่มี |
| G3 | แสดง **การ generalize** (ข้ามชนิด หรือ อย่างน้อยซื่อตรงกับข้อจำกัด) | พิสูจน์ว่าใช้ได้จริง ไม่ใช่ overfit ชุดเดียว | 🔴 ยังไม่มี |
| G4 | **เผยแพร่บน HF** พร้อม model card ซื่อตรง | โหลดได้ ชัดเจนว่าอะไรเป็นของเรา | ⚙️ รอรัน |
| G5 | **เทียบ baseline** (มีตัวเลขว่าเหนือกว่า/เทียบเท่า) | ข้ออ้าง "ดีกว่าวิธีอื่น" ต้องมีเลขรอง | ✅ ทำแล้วบางส่วน |

> **สรุปคำตอบ:** ตอนนี้ยัง **ไม่ใช่** โมเดลเรา (มีแค่ G5 บางส่วน) — ต้องทำ **G2 + G3** เป็นหลัก (G1/G4 เป็นแค่การรัน) → ดูงานค้างข้างล่าง

## 🔴 บล็อกที่ต้องแก้ก่อน (ยกเว้นนี้ โมเดลจะ "พูดไม่ได้")

### T1 — Annotate ground-truth masks ≥ 30 ภาพ [!!] ต้องใช้แรงคน
- ทำไม: G2 — ตัวเลข mIoU/Dice ที่ซื่อตรงต้องเทียบ mask มือ ไม่ใช่ pseudo ของ SAM3 (การเทียบ pseudo = circular)
- ทำอะไร: annotate binary mask (ขาว=ต้น) บน ≥30 ภาพ ครอบคลุม 3 คลาส (ยังไม่พร้อม ≥10 / พร้อม ≥5 / ตรวจเอง ≥5)
- ไฟล์: สร้าง `ground_truth_masks/<image>.png` · อ้างอิง `VALIDATION_PLAN.md` §2.2
- ความยาก: กลาง-สูง (งานมือ, ~2–4 ชม.) · **บุคคล: คุณ/ผู้ช่วย annotate** — ผมทำแทนไม่ได้ (จะไม่ซื่อตรง)
- หลังเสร็จ: รัน `benchmark_colab.py --gt ground_truth_masks` → ได้ **Level A mIoU** จริง

### T2 — รัน distillation บน Colab → เอา unet_model.pt [⚙️ รอคอมพิวเตอร์]
- ทำไม: G1 + G4 — ได้ตัวโมเดลจริง + อัปโหลด HF
- ทำอะไร: ตาม `docs/DISTILL_RUNBOOK.md` 4 เฟส (generate-pseudo→train→eval→hf-push)
- ความยาก: ต่ำ (โค้ด+runbook พร้อม) · ต้อง Colab GPU + HF token (เข้าถึง SAM3 gated)
- ออก: `unet_model.pt` (~2M params) + `unet_eval.csv` + repo บน HF

### T3 — Cross-species (G3) — [!!] ต้องมีภาพชนิดอื่น
- ทำไม: จุดขาย #1 "ใช้ข้ามชนิดได้โดยไม่ต้องฝึกใหม่" — ต้องพิสูจน์ด้วยชนิดใหม่
- ทำอะไร: ถ่าย 2–3 ชนิด (≥5 ขวด/ชนิด) ตาม `docs/CROSS_SPECIES_PROTOCOL.md` ในแล็บ → รัน `benchmark_cross_species.py`
- ความยาก: กลาง (งานมือถ่ายภาพ) · บุคคล: คุณ · โค้ด+protocol พร้อมแล้ว

> **ถ้าทำได้แค่ T1+T2 (ยังไม่ทำ cross-species):** เรียกว่า "โมเดลของเรา" ได้ **แบบจำกัด** — อ้างได้ว่าเป็นโมเดลกลั่นจาก SAM3 ที่ train+valid กับข้อมูลเรา แต่**ยังไม่พิสูจน์ข้ามชนิด** (ต้องบอกข้อจำกัดนี้ตรง ๆ)

## 🟢 ควรทำเพิ่ม (เสริมความน่าเชื่อถือ — ไม่บล็อก)

### T4 — เทียบ baseline กับตัว student [✅ base ทำแล้ว ต่อยอด]
- มี: baseline correlation + MAE/RMSE แล้ว (SAM3 > classical > YOLO-COCO)
- ต่อยอด: เพิ่ม `unet_student` เข้าไปเทียบใน `benchmark_traits.py` → ดูว่า student ใกล้ SAM3/มือแค่ไหน
- ความยาก: ต่ำ-กลาง

### T5 — Inter-rater (≥2 annotator) ให้ verdict/measure
- ทำไม: ตอบจุดอ่อน observer bias (Zhang et al., 2026) — คำนวณ ICC/Cohen's kappa
- ความยาก: กลาง (ต้องมีคน 2 คนวัดชุดเดียวกัน)

### T6 — ปรับปรุง root detection (ตอนนี้ 1/100)
- ทำไม: ระบบรากเป็นตัวชี้วัดความพร้อมอันดับ 1 ตาม literaturé แต่ใช้ไม่ได้ผ่านขวด
- ความยาก: สูง (ต้อง iterate prompt/วิธีบน GPU)

### T7 — Time-series growth curve
- ทำไม: ต่อยอด "บอกว่าพร้อม" → "ทำนายว่าจะพร้อมเมื่อไร" (จุดต่าง)
- **บล็อก:** ต้องถ่ายขวดเดิมซ้ำหลายสัปดาห์ (ข้อมูลปัจจุบันเป็นภาพ 100 ขวดคนละขวด ไม่ใช่ time-series) — ยังไม่ทำได้ตอนนี้

### T8 — Calibrate หน่วย geometric (PIXEL_TO_CM)
- ทำไม: ให้ค่า raw px→cm แท้ (ตอนนี้มีเฉพาะเชิงประจักษ์ proxy→cm) — ใช้กับทุกภาพ/ทุกชนิด
- ความยาก: ต่ำ-กลาง (ต้องขนาดขวดจริง + ตรวจจับขวดบน Colab)
