# 📥 คู่มือส่งข้อเสนอโครงงานในระบบ SIMS (VitroVision — YSC 2027)

> สำหรับส่งข้อเสนอโครงงาน ส่วนที่ 1 ของโครงงาน VitroVision (สาขา **CSAI — Computer Science and Artificial Intelligence / AI-ML**)
> อ้างอิง: YSC FAQ (`/faq.html` หมวด proposal-registration + special-forms) + คู่มือ YSC 2027
> ⚠️ ต้องสำเร็จ **ก่อนวันและเวลาปิดรับสมัคร** ในปฏิทินการประกวด (ดูประกาศ/คู่มือ)

---

## 0. ก่อนเริ่ม — ตรวจสิ่งที่ต้องมี

- [ ] บัญชี **SIMS** (https://www.nstda.or.th/sims) — สมัคร + **ยืนยันอีเมล** (เช็ค Junk mail)
- [ ] ไฟล์ข้อเสนอ **PDF ไฟล์เดียว** (โครงสร้างด้านล่าง) — เตรียมจาก `docs/proposal_th_submit.docx`
- [ ] ข้อมูลจริง: สมาชิกทีม, อาจารย์ที่ปรึกษา, ประวัติย่อ (ส่วน 14)
- [ ] เลือกสาขาให้ถูกต้องตั้งแต่แรก (**CSAI**) — เปลี่ยนหลังลงทะเบียนไม่ได้

---

## 1. เข้าสู่ระบบ SIMS

1. เปิด https://www.nstda.or.th/sims
2. ล็อกอินด้วย **อีเมลเป็น Username** + **Password ที่ตั้งไว้**
   - ถ้าเข้าไม่ได้/ขึ้น "ข้อมูลผิดพลาด" → ตรวจว่ายืนยันอีเมลแล้วหรือยัง
   - ลืม password อีเมล → ระบบแก้ให้ไม่ได้ (เป็นอีเมลส่วนตัว) ต้อง reset กับผู้ให้บริการก่อน

---

## 2. ลงทะเบียนโครงงาน

1. เมนู **กิจกรรม** → เลือก **YSC 2027** → **สมัครเข้าร่วม**
2. กรอกข้อมูลโครงงาน: ชื่อ (ไทย/อังกฤษ), **สาขา = CSAI**, รายละเอียด, สมาชิกทีม, อาจารย์ที่ปรึกษา
3. ตอบคำถามสถานะโครงการ (เช่น มีการทดลองกับคน/สัตว์ไหม) — ถ้าเลือก "ใช่" ระบบจะแสดงช่องส่งแบบฟอร์มเพิ่ม (2B/4/5 ตามกรณี)
   - *VitroVision = งานพืช ไม่มีคน/สัตว์ → ตอบ "ไม่" ได้ แต่จงระวังสาขา/แบบฟอร์มด้านล่าง*
4. **หมายเหตุ:** เฉพาะ **หัวหน้าโครงการ** ถึงจะเห็นเมนู "สร้างปก / แก้ไข / อัปโหลดไฟล์" (สมาชิก/ที่ปรึกษาเห็นไม่ครบ)
5. เปลี่ยนสาขาในระหว่างสมัคร = ลบโครงการแล้วลงทะเบียนใหม่ (ทำก่อนปิดรับสมัคร)

---

## 3. สร้างหน้าปกจากระบบ SIMS

1. เมนู **สร้างปก** (เฉพาะหัวหน้าโครงการ)
2. ระบบจะออก **หน้าปกพร้อมรหัสโครงการ** อัตโนมัติ → **ดาวน์โหลด**
3. ⚠️ หน้าปกนี้ต้องมาจาก SIMS เท่านั้น (ห้ามสร้างเอง/แก้ไข)

---

## 4. สร้างไฟล์ข้อเสนอ PDF ไฟล์เดียว

รวม 3 ส่วน (แล้วแปลงเป็น PDF):

```
[หน้า 1] หน้าปกจากระบบ SIMS            ← 1 page แรก
[หน้า 2–N] เนื้อหาข้อเสนอโครงงาน         ← ชื่อ/บทคัดย่อ/บทนำ/วัตถุประสงค์/สมมติฐาน/วัสดุ/วิธี/วิเคราะห์/Gantt/ความเสี่ยง/ประโยชน์/Gen-AI disclosure/บรรณานุกรม
[หน้าสุดท้าย] ประวัติย่อผู้พัฒนา + อาจารย์ที่ปรึกษา   ← ส่วน 14
```

- เนื้อหา + ประวัติย่อ: ได้จาก `docs/proposal_th_submit.docx` (อัปเดตสาขา CSAI แล้ว)
- แปลง docx → PDF (Word → Save as PDF หรือ LibreOffice)
- **มี 8 หัวข้อครบตาม FAQ:** ที่มา · วัตถุประสงค์ · สมมติฐาน · ขอบเขต · วิธีดำเนินงาน · แผนการดำเนินงาน · ประโยชน์ (+ ประวัติย่อ)

---

## 5. อัปโหลด + ยืนยัน

1. เมนู **อัปโหลดไฟล์** อัปโหลด PDF ที่รวมครบ
2. ตรวจสอบสถานะ + ไฟล์ที่อัปโหลด (`สถานะโครงการ`)
3. แก้ไขใหม่ได้เองจนกว่าปิดรับสมัคร

## ⚠️ ข้อควรระวังสำคัญ (สำหรับ VitroVision)

| ประเด็น | ผล |
|---|---|
| **สาขา CSAI** | เลือกถูกตั้งแต่แรก — เปลี่ยนทีหลังไม่ได้ |
| **Gen-AI** | ข้อเสนอ/บทคัดย่อต้องเป็นนักเรียนเขียนเอง (AI ช่วยตรวจ/ระดมคิดได้) + เก็บ prompt ใน Logbook — ต้องเปิดเผยใน 2A (รอบชิง) |
| **ผลนำร่อง [RESULT]** | ผลชุด 100 ขวด**รันจริงบน Colab เมื่อ 2026-08-26** แล้ว (หลังปรับเกณฑ์เป็นความสูง → verdict 75 พร้อมอนุบาล / 25 ยังไม่พร้อม) + validation เทียบมือผ่าน **H₂** (acc 0.755 / sens 0.917) — ได้หลักฐานครบ บรรจุเป็น [RESULT] ในข้อเสนอได้ แต่ยังมีข้อจำกัด root ใช้ไม่ได้ / หน่วยยังไม่ calibrate |
| **Form 2C** | ถ้าทำวิจัยในแล็บมหาวิทยาลัย/มีที่ปรึกษาจาก ม. → ต้องเตรียม 2C เพิ่ม (ส่งวันลงทะเบียนรอบชิง) |
| **Form 3 (Risk)** | งานแล็บ+สารเคมี → ต้องเตรียม |
| **หน้าปก SIMS** | สร้างจากระบบเท่านั้น ไม่มีทางอื่น |

## ❓ FAQ ที่อาจเจอ

- **ไม่เห็นเมนูสร้างปก/อัปโหลด?** → ต้องเป็นหัวหน้าโครงการ + ตรวจ info ให้ครบ
- **บัตรประชาชนถูกใช้ซ้ำ?** → แจ้งทีมที่เมนูแจ้งปัญหาใน SIMS
- **ไม่พบชื่อครูที่ปรึกษา?** → ให้ครูลงทะเบียนก่อน แล้วค้นด้วยเลขบัตร/ชื่อ
- **ต้องการเปลี่ยนสาขา?** → ลบโครงการ + ลงใหม่ (ก่อนปิดรับสมัครเท่านั้น)
