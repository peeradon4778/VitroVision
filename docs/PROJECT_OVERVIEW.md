# VitroVision — ภาพรวมผลงาน (ฉบับสรุปเข้มข้น)

> **หนึ่งหน้าจับใจความ:** เราใช้โมเดล AI เปิด (zero-shot) ชื่อ SAM3 มาวัดต้นเพาะเลี้ยงเนื้อเยื่อ**ในขวดแก้วปิด** โดยไม่ต้องเปิดขวด ไม่ทำลายต้น แล้วบอกได้ว่า**เมื่อไรควรย้ายออกอนุบาล** — ต้นทุนต่ำ (มือถือ + Colab ฟรี) ใช้ได้กับพืชหลายชนิดโดยไม่ต้องฝึกใหม่
> **เหมาะสำหรับ:** นำเสนอ/สอบอาจารย์ · อ่านจบเข้าใจงานทั้งหมดใน ~5–8 นาที

---

## บทนำ (Introduction)

การเพาะเลี้ยงเนื้อเยื่อ (in vitro) เป็นเทคโนโลยีขยายพันธุ์พืชที่สำคัญทั้งระดับโลกและไทย โดยเฉพาะกล้วยไม้ซึ่งเป็นสินค้าส่งออกสำคัญของประเทศ (Thammasiri, 2015) และการเพาะเลี้ยงด้วย bioreactor สำหรับปาล์มน้ำมัน/มะพร้าวช่วยเพิ่มความเร็วการขยายพันธุ์ 3–4 เท่า (ไบโอเทค, 2563) ทำให้สามารถผลิตต้นกล้าจำนวนมากได้ในพื้นที่จำกัด

อย่างไรก็ตาม ขั้นตอนที่เป็นคอขวดคือการตัดสินใจว่าต้นควรย้ายออกจากขวดไปอนุบาล (acclimatization) เมื่อใด ซึ่งปัจจุบันทำด้วยสายตาเป็นรายขวด ใช้แรงงานและค่าใช้จ่ายสูง (ค่าแรงคิดเป็น 60–70% ของต้นทุน — Bethge et al., 2023) ผลการตัดสินใจมีความแปรปรวนระหว่างผู้ประเมิน (Zhang et al., 2026) และการตัดสินใจเร็วหรือช้าเกินอาจทำให้เกิดความผิดปกติของเนื้อเยื่อ เช่น hyperhydricity หรือการตายของเนื้อเยื่อ ยิ่งไปกว่านั้น ต้นอยู่ในขวดแก้วปิด การเปิดขวดเพื่อวัดสภาพเสี่ยงการปนเปื้อน จึงจำเป็นต้องมีวิธีประเมินสภาพแบบไม่ทำลาย (non-destructive)

งานที่มีอยู่ (เช่น Regni et al., 2025) วัดพื้นที่ปกคลุมของต้นจากภาพ 3D แต่จำกัดเฉพาะชนิดพืช และยังไม่มีระบบต้นทุนต่ำที่ระบุความพร้อมอนุบาลแบบข้ามชนิดโดยไม่ต้องฝึกแบบจำลองใหม่ โครงงานนี้จึงพัฒนาและประเมินระบบคัดกรองความพร้อมอนุบาลแบบไม่ทำลายผ่านขวดแก้ว โดยใช้แบบจำลอง Segment Anything Model 3 (SAM3) ในโหมด Promptable Concept Segmentation (PCS) แบบ zero-shot แบ่งส่วนภาพต้นด้วยพรอมป์ข้อความ แล้วคำนวณลักษณะเชิงปริมาณเพื่อจัดกลุ่มความพร้อม — มุ่งให้เป็นระบบต้นทุนต่ำ (สมาร์ตโฟน + Google Colab + โมเดล open-source) ที่ทำงานข้ามชนิด

## 🧪 เราได้ผลจริงบ้างไหม (Pilot 100 ขวด)

ทำกับ**ภาพถ่ายจริง 100 ขวดพริกจินดา** (ถ่าย 3 วัน: 16 ก.ค. / 2 ส.ค. / 14 ส.ค. — เป็นชุดข้อมูล*ตามเวลา*ด้วย) รันผ่าน Google Colab (GPU ฟรี) ผลลัพธ์คือ:
- จัดกลุ่มได้ **75 ขวด "พร้อมอนุบาล" / 25 ขวด "ยังไม่พร้อม"**
- ลักษณะที่วัดได้ (จำนวนใบ/หน่อ/ความสูง/ความกว้าง/พื้นที่/สี) มี**ความสัมพันธ์กันอย่างสมเหตุผล** (เช่น พื้นที่กับพื้นที่ปกคลุม r = 0.95, ใบกับพื้นที่ปกคลุม r = 0.85)

## 🔦 ข้อค้นพบที่ทำให้งานนี้ "เจ๋ง" (ตรงนี้สำคัญสุด)

ตอนแรกเราคิดว่า "ความพร้อม" วัดจาก**ความแน่นเต็มขวด** (พื้นที่ปกคลุม = coverage) ซึ่งเป็นวิธีที่งานวิจัยเก่า ๆ ใช้กัน แต่เมื่อให้**ผู้เชี่ยวชาญ** (อาจารย์/ผู้ที่ทำงานจริง) มาตัดสินว่าแต่ละขวดพร้อมไหม แล้วเทียบกับที่ระบบคำนวณ — **ผลไม่ตรงเลย** (accuracy แค่ 0.43)

เมื่อวิเคราะห์ลึก ๆ พบว่า **ผู้เชี่ยวชาญไม่ได้ดู "ความแน่น" แต่ดู "ต้นโตพอ/สมบูรณ์/พร้อมย้าย"** ซึ่งสะท้อนด้วย**ความสูง/ขนาดของต้น** ไม่ใช่ความแน่น

พอเปลี่ยนกฎเป็นใช้**ความสูง** (`ความสูง ≥ 0.275`) ผลทันที: **accuracy = 0.755, sensitivity = 0.917** — แปลว่า**ตรวจจับ "พร้อม" ได้ 92% เกือบไม่พลาด** และผ่านเป้าหมายที่เราตั้งไว้ (H₂)

> **นี่คือคุณค่าที่แท้จริงของงาน:** เราพิสูจน์ว่า **ตัวชี้วัดที่คนใช้กัน (ความแน่น) จริง ๆ แล้วผิด** และ **ตัวที่ถูกคือความโต/ความสูงของต้น** — เป็นข้อค้นพบที่ท้าทายวิธีเดิม และเป็นผลมาจากการมี**ข้อมูลอ้างอิงจากมนุษย์**มาเทียบ

## 📊 สรุป validation ที่ได้

| สิ่งที่ตรวจ | ผล | ความหมาย |
|---|---|---|
| ความสัมพันธ์ของตัววัด (sanity) | r = 0.53–0.95 | ข้อมูลสอดคล้องตามชีววิทยา |
| ความถูกต้องของ feature กับมือ | height r = 0.64, ใบ r = 0.59 | พอใช้ (ปานกลาง) |
| **เกณฑ์ verdict vs ผู้เชี่ยวชาญ** | **acc 0.755 / sens 0.917** | **ผ่าน สมมติฐาน H₂** ✓ |

## ⚠️ ข้อจำกัดที่เราบอกตรง ๆ (ไม่ปิดบัง)

- **ระบบราก:** พอม "root" จับรากผ่านขวดแก้วแทบไม่ได้ (เจอแค่ 1/100) คราวนี้เลย**ไม่ได้ใช้รากเป็นตัวชี้วัดหลัก** (หันไปใช้ความสูงแทน) — ต้องแก้ต่อ
- **หน่วย ยังไม่เทียบ cm:** ค่าความสูง/พื้นที่ยังเป็นค่าสัดส่วน (proxy) ยังไม่ได้สอบเทียบเป็นเซนติเมตรจริง
- **ยังเป็น pilot เล็ก:** ชนิดเดียว (พริกจินดา) + ผู้ประเมินคนเดียว → ยังต้องยืนยันซ้ำกับผู้ประเมินหลายคน และขยายชนิด
- **ยังไม่มีตัวเลข "ดีกว่าวิธีอื่น":** การเปรียบเทียบกับ baseline (SAM2/YOLO-seg/คลาสสิก) ยังเป็นแผน

## 🚀 ต่อจากนี้ เราไปต่อยังไง (เส้นทางต่อยอย 4 ด้าน)

1. **จาก "บอกว่าพร้อม" → "ทำนายว่าจะพร้อมเมื่อไร"** เพราะเรามีข้อมูลถ่ายซ้ำ 3 วันอยู่แล้ว → สร้างกราฟการเจริญ + ทำนายวันย้าย (เปลี่ยนจากผู้ช่วย"ตรวจ"เป็นผู้ช่วย"วางแผน")
2. **ขยายหลายชนิด** เช่น กล้วยไม้/กล้วย กันพิสูจน์ว่าใช้ข้ามชนิดได้จริง (จุดขายหลัก)
3. **เปิดชุดข้อมูล** (ตามหลัก FAIR) + **เปรียบเทียบกับวิธีอื่น**อย่างครบถ้วน (mIoU/Dice) ให้ผลชัดเจนใช้ต่อได้
4. **ทำเป็นแอปมือถือ** ถ่ายภาพ → คำตอบในไม่กี่วินาที สำหรับแล็บจริง (เรามีส่วน Android เตรียมไว้แล้ว)

## 🏁 สรุปใจความใน 1 ประโยค

> **เราพิสูจน์ว่าใช้ AI แบบไม่ต้องฝึก (zero-shot) วัดต้นในขวดปิดได้จริง และค้นพบว่าตัวชี้วัดที่เคยใช้ (ความแน่น) ผิด — ตัวที่ถูกคือความโตของต้น — ต่อยอดสู่ระบบทำนายการเจริญ ข้ามชนิด ต้นทุนต่ำ สำหรับแล็บเพาะเลี้ยงเนื้อเยื่อ**
