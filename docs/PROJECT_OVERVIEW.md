# VitroVision — ภาพรวมผลงาน (ฉบับสรุปเข้มข้น)

> **หนึ่งหน้าจับใจความ:** เราใช้โมเดล AI เปิด (zero-shot) ชื่อ SAM3 มาวัดต้นเพาะเลี้ยงเนื้อเยื่อ**ในขวดแก้วปิด** โดยไม่ต้องเปิดขวด ไม่ทำลายต้น แล้วบอกได้ว่า**เมื่อไรควรย้ายออกอนุบาล** — ต้นทุนต่ำ (มือถือ + Colab ฟรี) ใช้ได้กับพืชหลายชนิดโดยไม่ต้องฝึกใหม่
> **เหมาะสำหรับ:** นำเสนอ/สอบอาจารย์ · อ่านจบเข้าใจงานทั้งหมดใน ~5–8 นาที

---

## บทนำ (Introduction)

การเกษตรและวิทยาศาสตร์พืชนำข้อมูลจากโลกกายภาพเข้าสู่ระบบดิจิทัล (real-world data → digital) อย่างรวดเร็ว ผ่านแนวคิดหลัก เช่น **digital twin** (แบบจำลองดิจิทัลเพื่อติดตาม/คาดการณ์) และ **การวัดฟีโนไทป์แบบ high-throughput ด้วย AI** (deep learning + computer vision) ซึ่งกลายเป็นแกนกลางของการเกษตรแม่นยำและการเฝ้าติดตามผลผลิต โดย AI ช่วยให้ติดตามผลผลิตแบบเรียลไทม์ ตัดสินใจแบบข้อมูลนำ และ**วัดแบบไม่ทำลาย** (non-destructive phenotyping) ได้ (Frontiers, 2025; MDPI Agronomy, 2026) แพลตฟอร์มอัตโนมัติ เช่น CropPhenoX, TraitDiscover ช่วยสกัดลักษณะจากภาพจำนวนมาก ขณะที่แบบจำลองพื้นฐานอย่าง Segment Anything Model (SAM) ช่วยแบ่งส่วนต้นแบบ zero-shot โดยไม่ต้องมีชุดข้อมูลขนาดใหญ่กำกับด้วยมือ อย่างไรก็ตาม ยังมีข้อจำกัดเรื่องการขาดแคลนข้อมูล การถ่ายโอนสู่สภาพแปลงจริง (generalization) และต้นทุนการสร้างชุดข้อมูล

การเพาะเลี้ยงเนื้อเยื่อ (in vitro) ซึ่งเป็นเทคโนโลยีสำคัญสำหรับการผลิตต้นกล้าพันธุ์ดีของพืชเศรษฐกิจหลากหลายชนิด ทั้งในระดับโลกและระดับประเทศ ก็เป็นอุตสาหกรรมที่กำลังเติบโต โดยตลาดมีมูลค่าประมาณ **USD 525–669 ล้านในปี 2025** และคาดโต **CAGR 8.5–9.6%** ต่อทศวรรษ ขับเคลื่อนโดยพันธุวิศวกรรม ยา และการเกษตร (Polaris, 2025)

แต่ขั้นตอนที่เป็นคอขวดที่สุดคือการตัดสินใจว่าเมื่อใดควรย้ายต้นออกอนุบาล (acclimatization) ซึ่งปัจจุบันทำ**ด้วยสายตาเป็นรายขวด** ใช้แรงงานมากและค่าใช้จ่ายสูง (ค่าแรงคิดเป็น 60–70% ของต้นทุน — Bethge et al., 2023) ผลการตัดสินใจมี**ความแปรปรวนระหว่างผู้ประเมิน** (Zhang et al., 2026) และการตัดสินใจเร็ว/ช้าเกินอาจทำให้เนื้อเยื่อผิดปกติ เช่น hyperhydricity หรือการตายของเนื้อเยื่อ ยิ่งไปกว่านั้น ต้นอยู่ใน**ขวดแก้วปิด** การเปิดขวดวัดสภาพเสี่ยงการปนเปื้อน จึงต้องใช้วิธี**ไม่ทำลาย (non-destructive)**

ในช่วงไม่กี่ปีมานี้มีงานเริ่มตอบโจทย์ เช่น ระบบ **"Phenomenon"** (Bethge et al., 2023) แบบ multi-sensor ต้นทุนต่ำสำหรับเฝ้าติดตามเพาะเลี้ยงเนื้อเยื่อในสถานที่จริงแบบไม่ทำลาย แพลตฟอร์ม **EcoBOT** สำหรับวัดฟีโนไทป์ด้วย AI/ML ภายใต้สภาพปลอดเชื้อ และงาน deep learning ที่จำแนกคุณภาพต้นกล้า (เช่น EfficientNet-B7-CBAM) หรือสร้างแบบจำลอง 3 มิติของต้นกล้า (PointNet++) รวมถึงแบบจำลองพื้นฐานสำหรับการแบ่งส่วน เช่น **Segment Any Plant** (2026) และ **SAM3** (Carion et al., 2025) ที่แบ่งส่วนตามพรอมป์ข้อความแบบ zero-shot อย่างไรก็ตาม งานด้านเพาะเลี้ยงเนื้อเยื่อส่วนใหญ่ยังเป็นแนวทาง "plant-to-sensor" (ติดตั้งเซนเซอร์ใกล้ต้น) และอยู่ในระยะเริ่มต้น

**ยังไม่มีระบบต้นทุนต่ำ** ที่ใช้เพียงสมาร์ตโฟนถ่ายภาพขวดแล้วแบ่งส่วนต้นด้วยแบบจำลองพื้นฐาน zero-shot **ผ่านขวดแก้วปิด** (ซึ่งมีปัญหา refraction, glare, ฝ้า, ไอน้ำ) เพื่อวัดลักษณะเชิงปริมาณและจัดกลุ่มความพร้อมอนุบาล**แบบข้ามชนิด**โดยไม่ต้องฝึกใหม่ (งานใกล้เคียง เช่น Regni et al., 2025 ใช้ภาพ 3D แต่จำกัดชนิด) โครงงานนี้จึงพัฒนาและประเมินระบบด้วย **SAM3 PCS** (พรอมป์ 5 คำ: plant, leaf, shoot, stem, root) คำนวณลักษณะเชิงปริมาณ 6 กลุ่ม และจัดกลุ่มความพร้อม — มุ่งให้เป็นระบบ**ต้นทุนต่ำ** (สมาร์ตโฟน + Colab + โมเดล open-source) ที่**ข้ามชนิด**และ**ไม่ทำลายตัวอย่าง**

## 🧪 เราได้ผลจริงบ้างไหม (Pilot 100 ขวด)

ทำกับ**ภาพถ่ายจริง 100 ขวดพริกจินดา** (ถ่าย 3 วัน: 16 ก.ค. / 2 ส.ค. / 14 ส.ค. — เป็นชุดข้อมูล*ตามเวลา*ด้วย) รันผ่าน Google Colab (GPU ฟรี) ผลลัพธ์คือ:
- จัดกลุ่มได้ **75 ขวด "พร้อมอนุบาล" / 25 ขวด "ยังไม่พร้อม"**
- ลักษณะที่วัดได้ (จำนวนใบ/หน่อ/ความสูง/ความกว้าง/พื้นที่/สี) มี**ความสัมพันธ์กันอย่างสมเหตุผล** (เช่น พื้นที่กับพื้นที่ปกคลุม r = 0.95, ใบกับพื้นที่ปกคลุม r = 0.85)

## 🔦 ข้อค้นพบที่ทำให้งานนี้ "เจ๋ง" (ตรงนี้สำคัญสุด)

ตอนแรกเราคิดว่า "ความพร้อม" วัดจาก**ความแน่นเต็มขวด** (พื้นที่ปกคลุม = coverage) ซึ่งเป็นวิธีที่งานวิจัยเก่า ๆ ใช้กัน แต่เมื่อให้**ผู้เชี่ยวชาญ** (อาจารย์/ผู้ที่ทำงานจริง) มาตัดสินว่าแต่ละขวดพร้อมไหม แล้วเทียบกับที่ระบบคำนวณ — **ผลไม่ตรงเลย** (accuracy แค่ 0.43)

เมื่อวิเคราะห์ลึก ๆ พบว่า **ผู้เชี่ยวชาญไม่ได้ดู "ความแน่น" แต่ดู "ต้นโตพอ/สมบูรณ์/พร้อมย้าย"** ซึ่งสะท้อนด้วย**ความสูง/ขนาดของต้น** ไม่ใช่ความแน่น

พอเปลี่ยนกฎเป็นใช้**ความสูง** (`ความสูง ≥ 0.275`) ผลทันที: **accuracy = 0.755, sensitivity = 0.917** — แปลว่า**ตรวจจับ "พร้อม" ได้ 92% เกือบไม่พลาด** และผ่านเป้าหมายที่เราตั้งไว้ (H₂)

> **นี่คือคุณค่าที่แท้จริงของงาน:** เราพิสูจน์ว่า **ตัวชี้วัดที่คนใช้กัน (ความแน่น) จริง ๆ แล้วผิด** และ **ตัวที่ถูกคือความโต/ความสูงของต้น** — เป็นข้อค้นพบที่ท้าทายวิธีเดิม และเป็นผลมาจากการมี**ข้อมูลอ้างอิงจากมนุษย์**มาเทียบ

## 📊 สรุป validation ที่ได้

| สิ่งที่ตรวจ | ผล | ความหมาย |

## ⚠️ ข้อจำกัดที่เราบอกตรง ๆ (ไม่ปิดบัง)

- **ระบบราก:** พอม "root" จับรากผ่านขวดแก้วแทบไม่ได้ (เจอแค่ 1/100) คราวนี้เลย**ไม่ได้ใช้รากเป็นตัวชี้วัดหลัก** (หันไปใช้ความสูงแทน) — ต้องแก้ต่อ
- **หน่วย ยังไม่เทียบ cm:** ค่าความสูง/พื้นที่ยังเป็นค่าสัดส่วน (proxy) ยังไม่ได้สอบเทียบเป็นเซนติเมตรจริง
- **ยังเป็น pilot เล็ก:** ชนิดเดียว (พริกจินดา) + ผู้ประเมินคนเดียว → ยังต้องยืนยันซ้ำกับผู้ประเมินหลายคน และขยายชนิด
- **ยังไม่มีตัวเลข "ดีกว่าวิธีอื่น":** การเปรียบเทียบกับ baseline (SAM2/YOLO-seg/คลาสสิก) ยังเป็นแผน

## 🚀 ต่อจากนี้ เราไปต่อยังไง (เส้นทางต่อยอย 4 ด้าน)

1. **จาก "บอกว่าพร้อม" → "ทำนายว่าจะพร้อมเมื่อไร"** เพราะเรามีข้อมูลถ่ายซ้ำ 3 วันอยู่แล้ว → สร้างกราฟการเจริญ + ทำนายวันย้าย (เปลี่ยนจากผู้ช่วย"ตรวจ"เป็นผู้ช่วย"วางแผน")
2. **ขยายหลายชนิด** เช่น กล้วยไม้/กล้วย กันพิสูจน์ว่าใช้ข้ามชนิดได้จริง (จุดขายหลัก)
3. **เปิดชุดข้อมูล** (ตามหลัก FAIR) + **เปรียบเทียบกับวิธีอื่น**อย่างครบถ้วน (mIoU/Dice) ให้ผลชัดเจนใช้ต่อได้
4. **ทำเป็นแอปมือถือ** ถ่ายภาพ → คำตอบในไม่กี่วินาที สำหรับแล็บจริง (เรามีส่วน Android เตรียมไว้แล้ว)
