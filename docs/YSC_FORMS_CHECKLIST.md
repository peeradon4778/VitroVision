## 📌 ความเกี่ยวข้องแบบฟอร์มกับ VitroVision (สรุปด่วน)

| ประเภท | ใช้/ไม่ใช้ | เหตุผล |
|---|---|---|
| มนุษย์ (Form 4 / consent) | ❌ ไม่ใช้ | งานศึกษา**พืช** ไม่มีผู้เข้าร่วมวิจัยมนุษย์ |
| สัตว์ (Form 5) | ❌ ไม่ใช้ | ไม่มีสัตว์มีกระดูกสันหลัง |
| Qualified Scientist (2B) | ❌ ไม่ใช้ | ไม่มี IRB/SRC กำหนดให้มี QS |
| สถาบันวิจัยกำกับดูแล (2C) | ❓ ต้องเช็ค | ถ้าทำในแล็บ/สถาบันที่มีการกำกับดูแล (RRI) |
| **Risk Assessment (Form 3)** | ✅ **น่าจะใช้** | งานแล็บ + สารเคมี (media/ฮอร์โมน/สารต้าน) — หน้าเว็บแนะนำให้ใช้ทุกโครงงาน |
| **Research Continuation (Form 6)** | ✅ **ต้องใช้** | VitroVision **v2 ต่อยอดจาก v1** + เคยส่งเวทีอื่น (PRIK/TTFR/Com Vision) |
