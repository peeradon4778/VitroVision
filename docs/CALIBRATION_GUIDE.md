# คู่มือ Calibrate หน่วย cm (PIXEL_TO_CM)

> เปิดใช้ feature `canopy_h_cm` / `canopy_w_cm` — ตอนนี้เป็น `None` เพราะยังไม่ calibrate
> วิธีมาตรฐาน: ใช้ขนาดจริงของขวดที่ถ่ายภาพเป็นไม้บรรทัดอ้างอิง

## วิธี calibrate (ทำครั้งเดียวต่อ "มุมกล้อง + ระยะ" ชุดเดียวกัน)

1. ถ่ายภาพขวด**เปล่าใบเดียวกัน**กับที่ใช้เลี้ยงต้น วางขวดให้**หน้าเดียวกับกล้อง** (ไม่เอียง) ระยะเท่ากับเวลาถ่ายจริง
2. ใช้ไม้บรรทัด/คาลิปเปอร์วัด**ความกว้างจริงของขวด** (หน่วย cm) เช่น กว้าง 6.5 cm
3. เปิดภาพในโปรแกรมใดก็ได้ (Paint/ImageJ) หา**ความกว้างเป็นพิกเซล**ของจุดกว้างสุดของขวด เช่น 620 px
4. คำนวณ: `PIXEL_TO_CM = ความกว้างจริง(cm) / ความกว้างพิกเซล = 6.5 / 620 ≈ 0.0105 cm/px`
5. ใส่ค่าใน cell คอนฟิก (notebook) หรือตัวแปรต้นไฟล์ (script):
   ```python
   PIXEL_TO_CM = 0.0105   # 1 px = 0.0105 cm
   ```

## ข้อควรระวัง (ส่งผลต่อความแม่นยำ)

- **เปลี่ยนระยะ/มุมกล้อง → ต้อง calibrate ใหม่** (scale เปลี่ยน) — บันทึกค่าไว้ต่อชุดภาพใน DEV_LOG
- ขวดเอียง → ค่ากว้างพิกเซลเพี้ยน — ให้วัดจากความกว้าง (ไม่ใช่ความสูง) เพราะเสี่ยงมุมน้อยกว่า
- ถ้าถ่ายผ่านกระจกหนา/มุมโค้ง: ค่าอาจคลาดเล็กน้อย (refraction) — ยอมรับได้ในงานนี้ ถ้าระยะคงที่
- ตรวจสอบ: วัดต้นไม้จริง 1 ต้น (ไม้บรรทัด) เทียบกับ `canopy_h_cm` ที่ได้ → ถ้าต่าง >10% ให้ recalibrate
